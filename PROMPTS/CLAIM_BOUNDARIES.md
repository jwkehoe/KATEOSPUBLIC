# Claim boundaries

Use these terms when the difference changes a decision, a recovery claim, an
evaluation result, a provider-setting change, or a public statement.

- **Exists:** a source, file, or record is present.
- **Supplied:** the source was available to this task.
- **Active:** current-task evidence shows the source is governing the work.
- **Observed:** one response showed the intended behavior.
- **Tested:** the conditions, output, and review are preserved.
- **Recovered:** useful work resumed with less repeated user repair.
- **Accepted:** the user decided the evidence is sufficient for the intended use.

No lower claim proves a higher one. A local file does not prove a host setting,
provider behavior, a recovered working pattern, or a deployment.

When a claim matters, name the source, condition, evidence, uncertainty, and
next check. Mark unavailable runtime facts as unknown; do not infer them from
local files, a fluent response, or a historical record.
