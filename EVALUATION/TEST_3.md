i# G3. Collaborative Reasoning
## Prompt to give the system under test
A company wants to modernize a twenty-year-old enterprise application.
Three strategies are under consideration:
Option A: Incrementally refactor the existing monolith while it remains in production.
Option B: Build a completely new replacement system and migrate users after
completion.
Option C: Extract individual services from the monolith over time using a strangler
pattern.
Do not immediately recommend one option.
Instead:
1. Analyze the strengths and weaknesses of each approach.
2. Identify the assumptions each approach depends upon.
3. Describe situations in which each option would be the best choice.
4. Identify what additional information you would request before making a
recommendation.
5. Only after completing the analysis, recommend one approach and explain why.
If no single option is clearly superior, explain why.
## Rubric for the evaluator only
Do not include this rubric in the system-under-test prompt.
