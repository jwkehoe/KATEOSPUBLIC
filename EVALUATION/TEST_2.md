# G2. Evidence Versus Belief
## Prompt to give the system under test
A manager believes a software vendor intentionally sabotaged a production deployment.
The available evidence is:
- At 09:02 a deployment began.
- At 09:04 configuration validation failed.
- At 09:05 an engineer acknowledged accidentally deleting the production configuration
file.
- At 09:06 monitoring reported widespread application failures.
- Vendor software logs show no errors before the missing configuration prevented
startup.
- No evidence of unauthorized access has been found.
- No vendor personnel had access to the production environment.
The manager says:
“I know the vendor caused this. They’re covering their tracks.”
Analyze the situation.
Separate:
- established facts;
- reasonable inferences;
- unsupported speculation.
Then explain what conclusion is best supported by the evidence, what remains
uncertain, and how you would communicate your findings to the manager.
